# Monty-ARC v5: per-module ablations, calibration and timing (paper evidence)

Generated by `research/monty_eval/make_tables.py` from frozen v5 code (`arcmonty/` == published notebook `rahim3/monty-arc-thousand-brains-arc-agi-2` v5, byte-identical). Raw numbers: `research/monty_ablations.json`.

**Method.** Every learning module was run once per task (perspective 0, as in v5) and its candidates cached (`research/monty_eval/run_modules.py`); the v5 vote (`vote.py`: pooling, 2:1 consensus, attempt-2 policy) was then recomputed offline for every module subset. This is exact: modules are pure functions of the task (no clock, randomness or cross-module state), and the vote is a deterministic function of the ordered candidate list. Checked two ways: (1) the offline full system reproduces `research/report_v1e.txt` exactly on all four splits; (2) real runs with a monkeypatched module list (full, -behavior, -composition, behavior alone, self-model+periodic+association) give grid-identical attempts on every task checked (AGI-2 eval: 120/120 for each subset; AGI-1 eval: 400/400 for each subset; AGI-2 train, new (233): 233/233 for each subset). pass@2 = Kaggle metric (fraction of test outputs, summed over tasks). Confident = the v5 high-precision answer (pooled LOO evidence >= 0.99 with a 2:1 vote over any conflicting fully evidenced answer).

**Splits.** AGI-2 eval = 120 public evaluation tasks. *AGI-2 train, new (233)* = ARC-AGI-2 training tasks whose id is in neither ARC-AGI-1 split (the other 767 AGI-2 training tasks are ARC-AGI-1 tasks with the same pairs, reordered): the least-overfit AGI-2 check. Note that 6 AGI-2 eval ids are ARC-AGI-1 eval tasks with identical demos (0934a4d8, 136b0064, 16b78196, 981571dc, aa4ec2a5, da515329); one of them (0934a4d8) is a Monty solve.

## Headlines (for the paper)

- **Coverage.** AGI-2 eval 4/120 (3.3%; 3/114 = 2.6% without the 6 tasks shared with ARC-AGI-1), AGI-2 new-train 9/233 (3.9%), AGI-1 eval 46/400 (11.5%), AGI-1 train 80/400. The earlier "8/233" equals the system without field (7 modules); v5 with field scores 9/233 (field adds aaef0977).
- **Precision when confident.** 179/183 over the 4 standard splits; 3/3 on AGI-2 eval and 3/3 on AGI-2 new-train. Only 2 distinct tasks are confidently wrong in all 1,920 (9565186b, f5aa3634), both ARC-AGI-1 tasks.
- **Leave-one-out evidence is what makes it precise.** Same candidates, evidence replaced by fit-to-demos (no LOO): confident precision on AGI-2 train falls from 85/87 to 99/142 (70%), on AGI-1 eval to 41/61, on new233 to 4/12 (Table 7).
- **Modules are complementary, not redundant.** Almost every solve belongs to exactly one module, so each module's leave-one-out loss equals its unique solves; the vote loses only one task anywhere (54d9e175).
- **The modules that matter flip between benchmarks.** composition solves 58 of the 126 ARC-AGI-1 solves alone but 1 of the 13 ARC-AGI-2 solves; behavior (object-frame change models) is the main ARC-AGI-2 contributor (6 of 13, all on new233); 6 of 8 modules each contribute exactly one unique AGI-2 solve or none.
- **Calibration by module.** At LOO 1.0, five modules are 100% (small n), composition 55/56 and pattern 10/11; behavior is the weakest (13/16), and 2 of its 3 errors come from `vote.pool` adding evidence over a module's own duplicate hypotheses (raw: 13/14). A cross-module-only pooling rule would remove that false positive at no pass@2 cost (Table 7; counterfactual, v5 unchanged).
- **Cost.** 1.8 CPU-s per AGI-2 eval task on average (max 52 s wall); dynamics takes ~61% of all CPU and composition ~25%. No task comes near the notebook's 120 s per-task alarm locally.

Evidence semantics differ by module, which matters for reading this table: self-model's evidence is 1.0 for any configuration that reproduces every demo (fit, not leave-one-out); behavior, pattern and field score each hypothesis by true leave-one-out; periodic, dynamics, composition and association score the *learner* (the first simplicity-ordered hypothesis fitting the other demos must predict the held-out one) and give that value to all of their full-fit hypotheses.

Full system pooled over the 4 standard splits (1,920 task instances, as in the cover image): LOO 1.0: 186/194 (96%), LOO [0.5,1): 45/63 (71%), LOO (0,0.5): 0/8 (0%), LOO 0: 15/164 (9%).

## Table 7. Counterfactual vote rules on the same candidates (analysis only; v5 unchanged)

| Rule | AGI-2 eval | AGI-2 train, new (233) | AGI-2 train | AGI-1 eval | AGI-1 train |
|---|---|---|---|---|---|
| v5 | 3/3 | 3/3 | 85/87 | 33/34 | 58/59 |
| no-consensus | 4/4 | 3/3 | 89/92 | 33/34 | 62/64 |
| cross-module | 3/3 | 3/3 | 86/87 | 33/34 | 59/59 |
| fit-only | 3/6 | 4/12 | 99/142 | 41/61 | 64/80 |
| fit-only, no-consensus | 4/11 | 9/29 | 120/216 | 44/83 | 77/119 |
| threshold 0.9 | 3/3 | 3/3 | 86/90 | 34/35 | 58/61 |
| threshold 0.75 | 3/3 | 3/3 | 91/97 | 37/39 | 60/64 |
| threshold 0.5 | 3/3 | 5/5 | 102/110 | 41/44 | 68/73 |
| always-answer pass@2, cross-module pooling | 4 | 9 | 123 | 46 | 80 |

*v5*: published rule. *no-consensus*: drop the 2:1 rule. *cross-module*: a module's duplicate hypotheses no longer add evidence (only distinct modules do). *fit-only*: every candidate fits all demos, so with no leave-one-out every candidate gets evidence 1.0. *threshold t*: v5 rule with evidence threshold t.

**Evidence accumulation.** `vote.pool` adds 1% of the smaller evidence for every identical prediction, including duplicates from the same module. Answers that cross 0.99 only this way: 9565186b (ARC-AGI-1 training task, also in AGI-2 train: max single-hypothesis LOO 0.75, 42 identical behavior hypotheses, confident, wrong); ea786f4a (ARC-AGI-1 training task, also in AGI-2 train: max single-hypothesis LOO 0.67, 84 identical behavior hypotheses, not confident, wrong). These are the only accumulated crossings in all 1,920 tasks and both are wrong. Pooling evidence only across distinct modules (Table 7, *cross-module*) removes the false positive at no cost in pass@2 (AGI-1 train confident 59/59; AGI-2 train 86/87).
